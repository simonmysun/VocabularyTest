VocabularyTest
==============

An approximate vocabulary test program

This is a student project for Advanced College English by Shaojie Liang, Lan Yang and Maoyin Sun. Report is available [here](https://maoyin.eu/VocabularyTest/slides/).

This is an experiment of CALT (Computer Assisted Language Testing) which tests the vocabulary size of a user.

Data is from SUBTLEXus. Code is written by Maoyin Sun.
